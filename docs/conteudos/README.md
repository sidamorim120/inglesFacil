# Conteúdos e Documentos Pedagógicos (PDFs)

Esta pasta é reservada para armazenar documentos em PDF, roteiros didáticos e materiais de apoio com conteúdos em inglês para conversão em atividades práticas do aplicativo.

## Como incluir novos conteúdos:
1. Adicione os arquivos `.pdf` diretamente nesta pasta (`docs/conteudos/`).
2. Notifique no chat quais módulos ou lições você deseja extrair (ex: Aeroporto, Hotel, Restaurante, Vocabulário do Dia a Dia, etc.).
3. O sistema fará a extração dos diálogos, vocabulário e exercícios, gerando automaticamente as questões com áudio, ditado, escrita e explicações didáticas em português.
